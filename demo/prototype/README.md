# 高保真演示原型（PC + App）

> **这是什么**：WorkLoom 熊猫电商运营系统的高保真可点击原型——以熊猫优选集团为例的完整经营态呈现。
> **怎么用**：**浏览器直接双击打开即可**，无需安装、无需后端、无需数据库。

| 文件 | 端 | 内容 |
|---|---|---|
| `pc.html` | PC 工作台 | 20 个功能入口全量可点：今日驾驶舱/经营目标/多店管理/收益分析/订单穿透/渠道运营/收益价格/价格健康/口碑差评/语音前台/客户回访/入退排房/客房布草/夜班驾驶舱/交接班/决断队列/围栏 R1–R20/技能市场/组织记忆/断点看板/排班安全/一店一档 |
| `app.html` | 移动端 | 四 Tab（今日/审批/门店/我的）+ 三手势审批 + 多店切换 + 夜班一键制动 + 现场演示按钮（制造差评/倒挂/订单高峰/断点） |

## 可交互点（不是静态图）

- **门店切换器**（右上角）：熊猫优选（单体）/ 西溪（民宿）/ 满陇（无人）/ 全店视图，一切换全页数据与模式标签联动
- **三手势审批**（决断队列）：采纳/驳回实时改变队列状态，含单调守卫驳回样本
- **夜班驾驶舱**：一键暂停 ⇄ 断点续跑，状态机实时变化
- **技能市场**：25 官方技能资产卡弹层 + 行业共享技能「一键加装」
- **FAQ 知识库**：候选问题一键「确认入库」
- **App 端样板间管家**：点「制造差评」，审批队列实时 +1
