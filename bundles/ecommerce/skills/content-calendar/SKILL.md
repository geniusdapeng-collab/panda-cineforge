# 内容日历与分发

## 何时调用
- cron 每周一：生成下周全平台内容日历。
- 事件驱动：热点事件（trend-radar 联动）插入即时分发任务。
- 大促日历自动预排；新品上市作战包联动。

## 输入契约
- 各平台排期需求：上新/促销/种草/直播预告（各作战军提报）。
- 素材库存：可用成品与在制品（video-batch-produce/brand-asset-lib）。
- 平台流量高峰表：各平台分时段流量规律。
- 平台分发通道：API（L1 优先）或 L3 剧本。

## 执行步骤
1. **需求汇总**。动作：汇总各平台排期需求与优先级。产出物：需求池。
2. **日历生成**。动作：生成平台×时段×内容类型三维矩阵日历，尊重各平台流量高峰差异（如抖音晚高峰/TTS 美区时差）。产出物：周内容日历。回执：日历版本号。
3. **素材匹配**。动作：匹配素材库存，缺口自动生成生产任务（short-video-script/video-batch-produce）。产出物：缺口清单+生产任务单。
4. **到点分发**。动作：API 优先（L1），无 API 走 L3 剧本；分发频次遵守平台限流规则。产出物：分发记录。回执：各平台发布回执，失败重试+归因。
5. **效果回流**。动作：追踪各平台数据回流，爆款内容自动加推相似素材；每周输出内容 ROI 排行（素材→流量→转化归因）。产出物：ROI 周报。

## 边界与围栏
- 对外发布必审：白名单内常规内容可 auto，其余进 review；发布内容须过 listing-compliance 校验（违规触发 **R11/R24**）。
- 热点插入内容 30 分钟内必须过审否则放弃（时效性纪律），不为赶热点跳过审核。
- 分发频次遵守各平台限流规则，防账号降权。

## 与其他技能的协作
- 供给：short-video-script、video-batch-produce、xhs-seeding（种草排期）、clip-distribute。
- 联动：trend-radar（热点插入）、new-product-launch（首波分发）。
- 归因：ROI 排行供 creative-iteration 与素材知识库沉淀。

## 验收用例
- 生成一周内容日历：覆盖 ≥3 平台且标注各平台流量高峰时段；模拟热点插入，系统在日历中重排并生成加急审核任务，30 分钟未过审自动放弃该热点。
