# 快速体检（快照快扫）

## 〇、定位

「先体检，再托管」客户旅程的**第一公里**：客户坐在现场，授权店铺后 15–30 分钟拿到《快速体检报告》——"原来我的店每年在漏这些钱"。这是购买决策的催化剂，也是质检模式（audit_only）的旗舰技能。

与持续体检的分工：
- **本技能（快照快扫）**：基于历史数据快照的存量问题，15–30 分钟一遍过——倒挂/毛利/库龄/ACoS/烧钱词/存量差评/侵权词/对账渗漏/绩效越限。
- **持续体检（inspection-suite，1–2 周）**：需要时间才能观察的问题——客服响应时长实测、SLA 履约率、趋势与峰值行为、夜班自治效果。

## 一、何时调用

- 售前演示：客户现场授权 1–N 家店铺后立即触发（目标：当场出报告）。
- 新客户接入质检模式时自动执行一次（基线快照），此后转入持续巡检。
- 客户手动触发"重新体检"（如大促后/整改后复查对比）。

## 二、输入契约

- 连接器只读快照（平台只读 scope 授权）：
  - 订单流水（近 90 天，含取消/退款标记）
  - 商品与库存（SKU 主数据/在库/在途/库龄/海外仓分布）
  - 广告账户（近 30 天计划/单元/关键词级花费与转化）
  - 评价与问答（存量未回复差评/评分分布）
  - 平台账单（最近 1–2 个结算周期）与店铺绩效指标
- 店铺档案（价格带/毛利红线/类目基准参数，缺失时用类目默认值并在报告中标注"按类目基准估算"）。
- 时间预算参数：默认 30 分钟硬上限（超时出部分报告并标注覆盖度）。

## 三、执行步骤（五线静态分析，一遍过）

1. **快照拉取与口径校准**（≤5 分钟）：动作=各平台连接器只读拉取，归一化为统一数据模型（13 平台字段映射）；产出物=快照数据集+覆盖度清单；回执=各源拉取回执（行数/时间窗/完整率）。
2. **价格健康线**：动作=同 SKU 跨平台价差扫描（倒挂 >15% 告警）→ 售价 vs 毛利红线（成本×1.15）破防清单 → 促销价异常（低于近 30 天最低价/价保冲突）；产出物=价格问题清单（含每单损失估算）；回执=计算过程快照。
3. **库存健康线**：动作=周转天数测算（>60 天积压清单+占用资金）→ 断货风险（可售天数 <7 天且在途为 0）→ 海外仓库龄分布（>90 天）与仓间失衡；产出物=积压/断货双清单（含资金占用与预期损失）；回执=计算过程快照。
4. **广告健康线**：动作=逐计划 ACoS vs 盈亏平衡点（=1−货品成本率−佣金率−物流费率−退货损耗率）→ 连续越线计划清单 → 高花费零转化关键词（烧钱词）→ 预算节奏异常（日内提前耗尽/长期闲置）；产出物=降本清单（**每项标注估算月可省金额**）；回执=计算过程快照。
5. **客服口碑与合规线**：动作=存量未回复差评（>48h 清单）→ 评分分布异常 SKU → 在售 Listing 侵权词/极限词扫描 → 绩效指标 vs 平台红线（ODR/迟发率/IPI）→ 疑似跟卖盘点；产出物=口碑风险清单+合规预警单；回执=扫描回执。
6. **对账复核线**（如有账单）：动作=最近结算周期账单与订单逐笔勾稽 → 差异分类（佣金错算/广告误扣/退款未冲抵/物流多收）；产出物=渗漏清单（含估算追回金额）；回执=勾稽差异明细。
7. **汇总成报告**：动作=五线结果按 P0/P1/P2 分级 → 每条附"问题+证据+建议动作+估算挽回金额" → 汇总一店一份《快速体检报告》+ 集团总览（按挽回金额排序的 Top10 行动清单）；产出物=报告卡片（IM 触达+工作台可查）；回执=报告事件 ID 与触达回执。

## 四、边界与围栏

- **全程只读**：audit-only patch 生效——一切平台写操作物理 block；本技能只向系统事件库写入发现与报告。
- **估算口径透明**：所有"挽回金额"标注计算口径与置信度（精确值/按类目基准估算/经验估计），禁止把估算说成确定值。
- **时间纪律**：30 分钟硬上限；某数据源超时→该线标注"未覆盖"并降级出部分报告，不阻塞整体。
- 不做什么：不做趋势预测（需观察期数据）、不做响应时长实测（需在线观察）、不做任何处置动作（只出建议）。

## 五、与其他技能的协作

- 产出 → `inspection-suite`（持续巡检接管，验证快扫发现并监测时变问题）
- 产出 → `morning-briefing`（体检发现并入晨报"风险"栏直至闭环）
- 报告中的整改项被客户确认后 → 对应域技能生成执行草案（影子模式起）
- 复购/复查场景：与上次报告 diff，产出《整改闭环率》对比卡

## 六、验收用例

- 接入含已知倒挂 SKU 的演示店铺，30 分钟内产出报告且该 SKU 出现在价格健康清单（含平台/价差/建议价）。
- 报告中每条估算金额均带口径标注；任一数据源缺失时报告正常产出且对应线标注"未覆盖"。
- 全程事件库无任何平台写操作记录（RuleImpact 全为只读动作）。
