# 新店开业作战包

## 一、何时调用
- 新店立项批准后自动生成作战包，开业日 T-30 启动。
- 关键节点（资质下证/审核通过/首单成交）事件驱动推进状态机。

## 二、输入契约
- 立项决议（平台/站点/类目/主体）；集团测款池 S/A 级已验证品清单。
- 合规 checklist 模板（VAT/商标/认证/类目资质，按平台站点版本化）。
- 冷启动资源：评价冷启动通道（Vine/催评日历）、测流广告预算额度、客服话术库。

## 三、执行步骤
1. **作战日历生成**：动作=输出节点日历——T-30 主体与账户注册→T-21 资质证照与类目审核→T-14 首批 SKU 刊登与合规检查→T-7 备货入仓与收款通道开通→T-3 价格与广告冷启动配置→T0 开业；产出物=作战日历；回执=日历事件组。
2. **合规前置核验**：动作=逐项核验 checklist，缺项 block 上架并升级；产出物=合规核验表；回执=逐项证据回执。
3. **首批 SKU 策略**：动作=从测款池选 S/A 级已验证品（禁止新店测全新品）；产出物=首批刊登清单；回执=选品依据引用。
4. **冷启动配置**：动作=评价冷启动日历、测流广告（预算硬上限）、多语言客服话术承接；产出物=冷启动包；回执=配置回执。
5. **首月密集看护**：动作=日报健康分/动销/绩效指标，异常即时升级；产出物=开业日报；回执=推送回执。
6. **T+30 复盘**：动作=达标转常规运营 SOP，不达标输出诊断（流量/选品/履约三分法）；产出物=复盘卡；回执=review-console 单据号。

## 四、边界与围栏
- 绑定 R8（新店/新平台首发刊登与改价全量必审，无 auto 通道，首月所有写动作降一级审批）。
- 绑定 R24（侵权词/侵权图上新 block，合规缺项前置 block 上架）。
- 绑定 R25（首批采购量 ≤测款上限 auto，超上限请示）。
- 主体/收款注册等外部动作只出指引不代操作；新店 90 天试验期预算封顶，追加必人工。

## 五、与其他技能的协作
- 选品：测款池/blue-ocean-mining（已验证品供给）；合规：compliance-sentinel、platform-rule-track。
- 冷启动：广告系技能（测流档位）、edm-automation（首购用户承接）。
- 交棒：T+30 达标后移交 shop-health-check 常规巡检与店长 Agent。

## 六、验收用例
- 正常路径：创建亚马逊欧洲站新店作战包 → 生成含 VAT 核验前置的 ≥10 节点日历。
- 异常路径：类目资质缺失 → T-14 节点 block 刊登并升级 P0。
- 围栏触发：新店刊登请求 → R8 强制 review；首批采购超测款上限 → R25 请示。

## 七、设计出处
- 来源：场景·14 店铺扩张节奏——开新店是"重决策+碎执行"组合，新店夭折多死于开业前 30 天的低级失误（资质缺项/首批品未验证/冷启动没节奏）；作战包把开新店变成可复用流水线，是扩张不摊大饼的机制保障。
