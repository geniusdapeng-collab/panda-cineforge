# 进口跨境运营

## 一、何时调用
- cron 每日同步保税仓库存与备案状态。
- 正面清单/跨境税则政策变更事件驱动全量重算。
- 大促（双11/黑五进口场）T-30 触发备货入区计划。

## 二、输入契约
- 商品主档（HS 编码/成分/原产地）、跨境正面清单与备案状态库。
- 保税仓库存与动销数据、入区周期参数；直邮三单（订单/支付/物流）对碰数据。
- 跨境综合税则（关税 0%+进口环节增值税/消费税按 70% 征收）与限值规则。

## 三、执行步骤
1. **双模式分线管理**：动作=保税仓模式（提前备货入区/清单申报/按订单出区清关）与直邮模式（海外直发/三单对碰）分线建账；产出物=双模式商品线台账；回执=台账版本号。
2. **合规引擎前置**：动作=逐 SKU 校验是否落在正面清单、是否完成备案、跨境综合税计税、单笔 5000 元/年度 26000 元限值；产出物=合规判定表；回执=判定明细。不在清单/未备案 block 上架。
3. **保税备货模型**：动作=按动销与入区周期计算备货量，保税仓临期/滞销预警（压货即死库存）；产出物=备货建议+预警清单；回执=测算事件 ID。
4. **三单对碰异常处理**：动作=申报失败/税单异常订单归集派单；产出物=异常工单；回执=派单回执。
5. **政策监听重算**：动作=正面清单调整/税则变更触发在售品合规重检与售价重算（R15）；产出物=重算清单+调价建议；回执=review 单据号。
6. **损益接入**：动作=跨境税+保税仓租+出区物流单列科目接入 sku-profit-ledger；产出物=进口线损益分录；回执=账本事件 ID。

## 四、边界与围栏
- 绑定 R24 思路（不在正面清单/未完成备案的商品 block 上架，物理不可刊登）。
- 绑定 R15（税则变更触发全量售价重算 review）、R6（保税仓周转 >60 天触发清仓预案请示）。
- 绑定 R20（保税仓备货采购付款必人工，大额升 L4）。
- 个人行邮税通道不得用于经营性囤货（写入 forbidden）。

## 五、与其他技能的协作
- 政策源：platform-rule-track（清单/税则变更信号）；合规：compliance-sentinel。
- 账务：sku-profit-ledger（单列科目）；库存：clearance-pricing（保税临期清仓）。
- 套利：cross-platform-arbitrage（进口线价格带纳入地图）。

## 六、验收用例
- 正常路径：跨境综合税规则变更 → 输出在售进口品重算清单与含税价调整建议。
- 异常路径：三单对碰失败订单 → 归集派单并挂处理倒计时。
- 围栏触发：某美妆 SKU 不在正面清单的上架请求 → block；保税仓周转 65 天 → R6 清仓请示。

## 七、设计出处
- 来源：场景·进口跨境——进口跨境是"政策搭台、库存唱戏"：正面清单决定能卖什么、保税仓库存决定亏不亏钱；计税/限值/备案做成上架前置引擎，让进口线既不错失政策红利也不踩走私红线。
