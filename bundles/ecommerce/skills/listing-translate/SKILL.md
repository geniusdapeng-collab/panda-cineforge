# 多语言本地化

## 何时调用
- 跨境刊登任务：自动生成翻译子任务（listing-factory 联动）。
- 目标站点新增：批量触发存量链接翻译。
- 目标国法规/平台词库更新后：存量译文复检。

## 输入契约
- 源文案：标题/五点/详情/A+ 全文。
- 术语库：品牌词/产品词/参数单位锁定表（强制不译错）。
- 目标国合规词库：广告宣称限制、认证宣称白名单、类目法规（如德国包装法、欧盟 CE 宣称）。
- 当地搜索习惯词库（keyword-seo 跨境词库）。

## 执行步骤
1. **源文案提取**。动作：按字段提取源文案并标记可译/不可译区（品牌词/型号/认证编号）。产出物：分段任务单。
2. **术语对齐**。动作：术语库强制锁定——品牌词、产品词、参数单位（mAh/尺码标准）不译错不遗漏。产出物：术语映射表。回执：锁定命中清单。
3. **翻译+本地化改写**。动作：AI 翻译后本地化改写——度量衡换算、日期格式、文化禁忌规避、当地搜索习惯词替换。产出物：译文草稿。
4. **双检**。动作：敏感词+合规词双检（目标国法规：功效宣称/医疗词汇按白名单校验）。产出物：检查报告；命中项附替换建议。
5. **母语级质检**。动作：抽样质检——语义保真度+SEO 词覆盖度评分，不达标返工。产出物：质检评分。回执：译文挂载刊登流程的回执。

## 边界与围栏
- 译文发布前合规双检为硬闸门：侵权词/违规宣称触发 **R24/R11** block。
- 品牌词与认证宣称不可自由发挥：译文不得新增源文案没有的承诺性表述（防虚假宣传，**R11**）。
- 医疗/功效类词汇按目标国法规白名单校验，白名单外一律替换或删除。
- 质检抽样比例不低于 10%，新站点首批全检。

## 与其他技能的协作
- 调用方：listing-factory（刊登管线内嵌）、a-plus-content（A+ 跨站点复用）。
- 词库：keyword-seo（当地搜索词）、listing-compliance（合规词库共享）。
- 复检联动：platform-rule-track（法规变更触发复检）。

## 验收用例
- 充电宝详情译德语：锁定"mAh/Anker"等术语不译错，替换为德语区搜索习惯词，拦截任何源文案未有的功效宣称。
- 译文新增"100% 安全"类源文案没有的承诺：双检拦截并退回。
