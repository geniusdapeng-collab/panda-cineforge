# 投放自动驾驶

## 一、何时调用
- cron 每 2 小时全量巡检各平台广告账户。
- 夜班 22:00–08:00 自治窗口持续值守；异常信号（花费突增/转化断档/预算提前耗尽）实时触发。

## 二、输入契约
- 各平台账户实时数据（展现/点击/转化/花费/ACoS）。
- SKU 生命周期阶段（sku-lifecycle）、策略模板库、白名单动作清单。

## 三、执行步骤
1. **聚合数据**：动作=聚合各平台账户实时盘面；产出物=账户巡检快照；回执=平台 API 回执，数据断流标「未核实」只观察不动作。
2. **匹配模板**：动作=按 SKU 生命周期匹配策略模板（导入期测指标/成长期卡 ROI/成熟期守利润/衰退期降档收兵）；产出物=模板匹配表；回执=生命周期判定引用。
3. **执行白名单动作**：动作=分时出价微调、低效关键词降竞价、预算在广告组间再平衡、否词增补（联动 ppc-keyword-mining）；产出物=动作指令集；回执=逐动作平台回执。
4. **过闸分流**：动作=所有动作前置过 acos-fuse 保险丝（R3）与幅度闸门（R4），超限动作转 review；产出物=过闸记录/审批卡片；回执=RuleImpact 事件。
5. **夜班自治**：动作=夜班窗口仅执行白名单动作（R16），白名单外一律挂起；一键暂停响应 ≤60s；产出物=夜班值守日志；回执=动作与挂起清单。
6. **出日志**：动作=生成《自动驾驶日志》（每小时动作清单+依据+效果预估），汇入次日晨报"已完成"栏；每周输出模板效果对比反哺迭代；产出物=日志+周报；回执=归档事件 ID。

## 四、边界与围栏
- 绑定 R3（保险丝前置）、R4（预算上调>30% 必审）、R16（夜班白名单自治）、R17（夜班调价≤3% auto 越线挂起）。
- 绝不做什么：绝不执行白名单外动作（新建计划/换素材/改定向/超幅度调整必 review）；绝不绕过保险丝；绝不在数据断流时盲调。

## 五、与其他技能的协作
- 闸门：acos-fuse、ads-budget-pacing；词库：ppc-keyword-mining；分时：dayparting。
- 汇报：morning-briefing（日志进晨报）；模板迭代反哺各平台投放技能。

## 六、验收用例
- 正常路径：夜班时段对测试账户执行 ≤N 次白名单动作，全部过闸门留痕。
- 异常路径：注入"预算 22:30 提前耗尽"信号 → 触发降档动作并写入决策包。
- 围栏触发：白名单外的新建计划请求 → 挂起转 review。

## 七、门道出处
- 门道⑤广告纪律（报告一盯盘耗时痛点）：投手 70% 盯盘动作是规则明确的机械调整；白名单自治让人类投手只做策略与例外——一人管 10 个账户变一人管 100 个。
