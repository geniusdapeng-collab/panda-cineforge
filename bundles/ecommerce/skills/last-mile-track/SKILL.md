# 尾程追踪与妥投率

## 一、何时调用
- 跨境包裹交尾程承运商即开启逐票追踪。
- 妥投率日报 cron 每日 07:00。
- 单线路妥投率周环比降 >3 个百分点触发线路诊断。

## 二、输入契约
- 尾程承运商追踪 API（无 API 线路走确定性剧本抓取）。
- 运单清单、目的国、买家联系方式（脱敏网关后）。
- 线路级基准：妥投率、平均时效、派送失败率、追踪断更率。

## 三、执行步骤（操作手册）
1. 逐票状态机：已揽收/运输中/派送中/已妥投/异常滞留/退回，状态变更事件化。
2. 体验前置：派送失败即时触发买家触达（改约/自提点引导），话术取自过审模板库。
3. 滞留 >72h 自动升级 shipping-exception 进入异常处置流水线。
4. 线路级指标：分国家×承运商统计妥投率/时效/失败率/断更率。
5. 诊断与切换建议：劣化线路输出替代承运商对比卡（时效×价格×妥投率）。
6. 月度尾程记分卡反哺 freight-forward 头程选型与店铺体验分管理。

## 四、边界与围栏
- 只读追踪为主；改约/重派等写动作限白名单承运商接口。
- 买家触达数据必经脱敏网关（对齐 R22 PII 管控）；话术只用合规过审库。
- 不为冲妥投率虚假标记签收，R11 直接 block。
- 夜班时段告警推送遵守 R16 白名单纪律。

## 五、与其他技能的协作
- 异常票件升级 shipping-exception；记分卡反哺 freight-forward 与 cn-express-optimize；妥投数据供 account-health 绩效看板与店铺体检。

## 六、验收用例
- 正常：巴西线路妥投率 91%→87%，触发线路诊断并输出 2 家替代承运商对比卡。
- 时效：派送失败票件 2 小时内触发买家改约触达。

## 七、门道出处
- 非★技能。来源：场景·跨境体验指标（尾程妥投率与追踪透明度决定店铺评分、纠纷率与平台流量分配；巴西/中东等新兴市场妥投率是生死线）。
