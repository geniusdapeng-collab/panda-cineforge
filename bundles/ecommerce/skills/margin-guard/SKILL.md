# 毛利红线守护 ★

## 一、何时调用
- 管线内嵌闸门：一切改价、促销、优惠券、套装、清仓动作提交前强制前置执行。
- 每日 03:30 随 sku-pl 核算完成后，全量复验存量在售 SKU。

## 二、输入契约
- 动作申请单：SKU、拟成交价、动作类型、生效时间。
- 该 SKU 最新损益瀑布：货品成本/平台佣金/物流/广告假设/退货损耗/税费（来自 sku-pl）。
- 客户 Patch 红线阈值（只可收紧不可放宽，默认净利率红线 5%、保本线 0）。

## 三、执行步骤
1. **取拟成交价**：动作=解析动作申请中的拟成交价（券后价/组合摊销价须折算到最终到手价）；产出物=标准化拟成交价；回执=折算口径说明。
2. **调损益瀑布**：动作=调取该 SKU 最新损益瀑布全科目；产出物=科目清单+数据时间戳；回执=sku-pl 读取回执，科目缺失标「未核实」并按 block 处理（宁可错杀）。
3. **测算净利**：动作=计算拟成交价下预测净利率与单位净利；产出物=测算明细表；回执=计算公式与参数留痕。
4. **三级判定**：动作=净利率 ≥10% 放行（auto）；5%–10% 生成 review 卡片，附"降哪项费用、降多少才能救回"的反解；<5% 或单位净利为负 → block 物理阻断并写明被哪条科目打穿；产出物=判定结果（pass/review/block）；回执=判定卡片推送审批人。
5. **留痕回放**：动作=判定结果写入五元事件 RuleImpact（rule_id/before/after/basis/result）；产出物=RuleImpact 事件；回执=事件 ID，可回放。

## 四、边界与围栏
- 绑定 R2（毛利红线熔断：售价 < 货品成本×1.15 物理不可执行）、R1（单日降价幅度闸门，本闸门之外叠加校验）、R30（高危审批超时升级而非放行——本闸门永不因超时跳过）。
- 绝不做什么：绝不执行任何改价（只判定不执行）；绝不豁免红线（无白名单、无特批通道）；绝不放宽客户 Patch 阈值。

## 五、与其他技能的协作
- 被调用方：dynamic-reprice、promo-planner、coupon-strategy、gift-strategy、clearance-pricing、fx-reprice 提交前必过本闸门。
- 数据源：sku-pl（损益瀑布）、pricing-matrix（保底价锚点）。

## 六、验收用例
- 正常路径：促销申请测算净利率 12% → pass 放行，RuleImpact 留痕。
- 围栏触发：150 元降到 99 元（净利率 -3%）→ block，指出退货损耗科目为主因，并给出"净利率回正所需最低成交价"。
- 中间档：净利率 7% → review 卡片附费用反解。

## 七、门道出处 ★
- 门道③"任何降价不得低于毛利红线"：报告证明粗算与实际净利有近 50% 缺口；把红线做成管线内不可绕过的物理闸门，等于给每笔交易装上"亏钱不可能成交"的保险。
