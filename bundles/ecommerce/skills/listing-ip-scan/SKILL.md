# 刊登侵权扫描 ★

## 一、何时调用
- 新 listing 创建/批量刊登导入即时触发（上架前置闸门）。
- 在售 listing 定期 cron 复扫；侵权词库更新后全量重扫。
- 图片素材入库即触发图片合规扫描。

## 二、输入契约
- 标题/五点/描述/A+ 文案；主图/场景图/A+ 图。
- 四维词库（商标词/专利关联词/版权素材描述/平台违禁词）与视觉比对库；自有品牌授权证书库。

## 三、执行步骤（操作手册）
1. **文本扫描**：文案 × 四维词库——商标词库（含变形拼写/谐音规避识别）/专利关联词/版权描述/平台违禁词（医疗宣称/绝对化用语），逐词标注风险等级。
2. **图片扫描**：图片 × 视觉识别——知名 IP 形象/品牌 Logo/版权图库比对/认证标志伪造（假 CE/FDA 标）。
3. 风险三级处置：高危（明确注册商标/知名 IP）→ block 刊登；中危（近似/待确认）→ review 卡片附风险说明；低危（通用词误伤）→ 白名单记录。
4. 整改建议：高危词给出替代表述方案（不损转化的合规改写）。
5. 白名单管理：自有品牌授权词凭证书入库，版本化留痕。
6. 扫描底稿归档：每个 listing 的扫描报告哈希存证，被诉时即为"已尽合理注意"证据。

## 四、边界与围栏
- R24：高危侵权词/图上新 block，扫描未通过的 listing 物理不可发布。
- 词库与图库版本化，更新后重扫范围留痕；近似判定标注置信度，低置信转人工而非放行。
- 不使用未授权图库做比对训练（自身合规，R11 同纪律）。

## 五、与其他技能的协作
- 词库来自 ip-shield 攻防情报与 compliance-sentinel 新规；上架闸门卡 listing-factory；底稿供 appeal-kit 证据链；高危命中同步 ip-shield 评估攻防。

## 六、验收用例
- 围栏：含某知名品牌谐音变形词的标题被识别并 block 刊登。
- 放行：含授权证书的自有品牌词凭白名单放行，留痕证书版本。

## 七、门道出处
- ★门道⑩固化技能：扫描是上架前唯一零后悔成本的关卡，底稿顺带构成被诉时的减责证据链。
