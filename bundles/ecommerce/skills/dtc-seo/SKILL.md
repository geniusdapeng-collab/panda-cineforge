# 独立站SEO

## 一、何时调用
- cron 每周刷新关键词排名与流量数据。
- 新内容发布 T+7/T+30 排名追踪。
- Google core update 等算法更新事件触发全站影响评估。

## 二、输入契约
- 站点数据：Search Console/分析工具的关键词排名、自然流量、索引覆盖率。
- 关键词资产库（搜索量×转化意图×竞争度三维打分）；内容工场产能排期。
- SKU 卖点库与口碑资产（好评/UGC）；技术巡检项清单（速度/移动适配/结构化数据/死链）。

## 三、执行步骤
1. **关键词资产库**：动作=品类词/场景词/问题词（how to/what is/best for）三层建库，按搜索量×转化意图×竞争度排序；产出物=词库版本；回执=数据源快照。
2. **内容矩阵规划**：动作=按缺口排产——博客指南（问题词）/类目聚合页（品类词）/对比测评页（商业词），联动内容工场生产；产出物=内容排产表；回执=排产单据。
3. **技术 SEO 巡检**：动作=站点速度/移动适配/结构化数据/死链/索引覆盖率周检，异常派单；产出物=技术体检卡+工单；回执=巡检回执。
4. **外链与权威建设**：动作=输出合规外联机会清单（行业目录/客座博客/PR 提及），逐条跟进；产出物=外联管线；回执=获取回执。购买外链/PBN 一律拒绝。
5. **排名流量归因**：动作=页面→关键词→自然流量→加购→成交漏斗追踪，内容与 SKU 转化关联打标；产出物=归因报表；回执=漏斗数据回执。
6. **算法更新应对与月报**：动作=流量波动归因（内容质量/技术/外链）输出整改清单；月度输出自然流量占比/获客成本对比付费渠道/内容资产复利曲线；产出物=整改清单+月报；回执=归档事件 ID。

## 四、边界与围栏
- 绑定 R11（购买外链/PBN/关键词堆砌等黑帽手段 block+forbidden；功效宣称虚假宣传同 block）。
- 绑定 R24（内容涉侵权词/侵权图 block 发布）。
- 对外发布内容必审（白名单内例行更新可 auto）；功效/宣称表述受 listing-compliance 同一词库校验。
- 不承诺排名结果——只说资产与趋势，禁止"保证上首页"类表述。

## 五、与其他技能的协作
- 生产：内容工场/creative-iteration（内容供给）；合规：listing-compliance（词库校验）。
- 转化承接：edm-automation（自然流量订阅沉淀）、member-ops（首购转会员）。
- 战略：cross-platform-arbitrage（独立站价格带定位）、门道②免费流量结构报表。

## 六、验收用例
- 正常路径：某指南发布 30 天后目标词排名 45→18 → 月报计入内容资产并归因其自然流量带来的加购。
- 异常路径：算法更新后流量跌 30% → 输出归因（内容/技术/外链）与整改清单。
- 围栏触发："购买 500 条外链"建议 → R11 block 并记录。

## 七、设计出处
- 来源：门道②——独立站是免费流量占比最高的阵地，SEO 流量成本趋近于零且资产可累积，但 3–6 个月见效期劝退多数卖家；系统化排产+复利曲线可视化让延迟满足变成看得见进度的投资，独立站才成为利润结构而非成本中心。
