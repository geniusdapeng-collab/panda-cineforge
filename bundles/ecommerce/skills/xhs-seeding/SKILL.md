# 小红书种草作战

## 何时调用
- 新品种草期：自动生成作战计划（new-product-launch 联动）。
- 事件驱动：爆文出现（互动增速超基线 3 倍）时触发跟投放大。
- 每月：种草效果复盘与归因。

## 输入契约
- 目标商品档案：卖点/目标人群/价格带。
- 场景词库：需求型搜索词（"通勤穿搭""油皮粉底"类）。
- 达人库：候选达人数据（真实互动率/粉丝画像/历史带货数据/报价）。
- 平台报备规则与广告法词库。

## 执行步骤
1. **人群与场景词拆解**。动作：拆解目标人群与搜索场景词，确定卡位词清单。产出物：场景词清单。回执：词库来源与搜索量数据。
2. **内容矩阵制定**。动作：制定种草内容矩阵——干货教程/测评对比/场景植入/买家秀征集的配比。产出物：内容矩阵表。
3. **达人合作管理**。动作：选号（真实互动率与粉丝画像匹配度双指标）→brief 生成→发布档期→数据回收，≥5 个候选达人各附选号依据。产出物：达人合作单。回执：brief 合规校验结果。
4. **评论区运营**。动作：置顶答疑/埋购买引导/负面舆情响应（负面 2h 内响应）。产出物：评论区运营记录。
5. **爆文加推与归因**。动作：爆文识别触发加推与搜索词卡位；月度种草归因（小红书搜索量→进店→成交链路估算）。产出物：归因月报。回执：加推审批与效果数据。

## 边界与围栏
- 笔记发布必审；功效宣称受广告法词库校验（违规触发 **R11**）。
- 软广必须按平台规则报备：虚假种草与刷单炒信写入 forbidden（**R11** block，零容忍）。
- 达人合作付款必人工确认（**R20**）。
- 评论区不做虚假互动、不批量养号。

## 与其他技能的协作
- 排期：content-calendar（种草进全平台日历）；素材：video-batch-produce、brand-asset-lib。
- 联动：new-product-launch（新品种草期）、keyword-seo（场景词与搜索卡位共享）。
- 归因数据供 biz-dashboard 与门道②免费流量占比看板。

## 验收用例
- 生成种草作战计划：含场景词清单、内容矩阵配比、≥5 个候选达人及选号依据（互动率+画像匹配数据），brief 通过合规词校验。
- 模拟爆文（互动增速 3.2 倍基线）：自动触发加推建议与搜索词卡位任务。
