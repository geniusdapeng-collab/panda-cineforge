# EDM私域自动化

## 一、何时调用
- 事件流驱动：新订阅/新客首单/加购未付款（弃购）/订单签收后 N 天/久未购买达唤醒阈值。
- cron 每周流程效果复盘；大促前 T-14 触发大促私域战役排期。

## 二、输入契约
- 行为事件流（浏览/加购/购买/退货/签收）与 RFM 人群包（数据大脑圈选）。
- 营销授权记录（GDPR/CASL 授权状态、退订名单实时同步）。
- 模板库+SKU 卖点+口碑资产（好评截图/UGC）；频控参数（单用户周触达上限）。

## 三、执行步骤
1. **受众分层取数**：动作=基于 RFM 与行为事件圈选人群包，先过授权校验（未授权/已退订物理排除并记录原因）；产出物=合规人群包；回执=授权核验明细。
2. **欢迎流编排**：动作=新订阅触发 3–5 封序列——订阅欢迎（即时）→品牌故事（+1 天）→新人券（+3 天）→首单引导（+5 天），首单达成即跳出序列；产出物=序列实例；回执=逐封发送回执。
3. **弃购挽回流**：动作=三波递进节奏——2h 纯提醒（不加促销）→24h 痛点内容+评价举证→72h 限时券收尾，任一波转化即终止后续；三波内容必须差异化，禁止同模板连发；产出物=挽回序列；回执=各波次发送与转化回执。
4. **复购唤醒流**：动作=按品类消耗周期预测复购时点，到期推送补货提醒+老客专享；超周期 1.5 倍未购升级唤醒力度（联动 member-ops 挽留层）；产出物=唤醒清单；回执=发送回执。
5. **内容组装过审**：动作=模板+卖点+口碑资产自动组装，逐封过发布审核（白名单内流程化邮件可 auto）；产出物=待发邮件；回执=审核记录。
6. **频控发送与归因**：动作=单用户周触达上限校验后发送；打开率/点击率/挽回率/复购贡献金额逐流程核算回写模板优劣标签；月度输出私域 GMV 占比/复购率/退订率/单客 LTV 曲线；产出物=归因报表+月报；回执=归档事件 ID。

## 四、边界与围栏
- 绑定 R22（用户数据按授权范围使用、经脱敏网关，PII 不出域）。
- 绑定 R10（优惠券面额/对外承诺超阈值 review）、R11（购买邮件列表 block；虚假倒计时/虚假库存紧张话术 block）。
- 退订请求即时生效，不得设障；频控上限客户 Patch 只收紧。

## 五、与其他技能的协作
- 人群：member-ops（RFM 分层与挽留层联动）、audience-persona。
- 内容：creative-iteration（模板迭代）、口碑资产库。
- 战役：promo-war-room（大促私域排期）、coupon-strategy（券成本核算）。

## 六、验收用例
- 正常路径：100 个弃购事件 → 按 2h/24h/72h 三波发出差异化内容并输出各波次挽回率。
- 异常路径：某用户授权缺失 → 自动排除并记录原因，不得发送。
- 围栏触发：券面额超阈值 → R10 review；导入外部购买名单 → R11 block。

## 七、门道出处
- 门道②免费流量结构：私域用户复购率比公域高 47%、LTV 提升 3 倍以上，复购订单流量成本趋近于零是纯利发动机；但 90% 卖家的 EDM 停留在"节日群发"——三大自动化流把私域从广播喇叭变成按行为触发的精密管道，是免费流量结构里见效最快的一环。
