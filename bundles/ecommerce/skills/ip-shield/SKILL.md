# 知识产权护盾 ★

## 一、何时调用
- 新品牌/新品类立项触发自有 IP 布局评估。
- cron 每周监控核心市场商标/专利动态（抢注监测）；对手专利到期/无效线索月度扫描。
- 收到侵权投诉/律所函件即时触发应诉流程。

## 二、输入契约
- 自有 IP 台账：商标（注册国/类别/状态/续展日）、专利、版权登记。
- 在售 SKU×销售国别×类目清单；核心市场商标公告数据。
- 投诉/函件原文与平台通知。

## 三、执行步骤（操作手册）
1. 自有 IP 台账建档：续展与宽展期倒计时管理。
2. 布局缺口扫描：在售 SKU×国别×类目 vs 台账，输出"裸奔市场"清单（有销售无商标的国家）与注册优先级。
3. 抢注监测：核心市场商标公告近似监测，命中抢注线索生成异议/无效宣告评估卡。
4. 被诉分级应对：平台投诉（按 appeal-kit 流程举证）/律所函件（涉 TRO 风险 P0 升级+资金冻结预案联动 settlement-track）/诉讼（外部律师对接清单与证据卷）。
5. 攻防情报：竞品专利布局分析（哪些绕不开/哪些快到期）、类目高发侵权词库维护，反哺 listing-ip-scan。
6. IP 健康月报：台账覆盖率、裸奔市场数、在办案件状态。

## 四、边界与围栏
- 涉法律定性（侵权成立与否）只由持证律师输出，系统只做证据归集与流程管理。
- 异议/诉讼决策必人工；不使用抢注手段攻击竞品（写入 forbidden，R11 同纪律）。
- 律所函件 24h 内必须人工接管；高危响应超时按 R30 升级。

## 五、与其他技能的协作
- 词库反哺 listing-ip-scan；应诉证据卷供 appeal-kit；TRO 资金冻结联动 settlement-track/cash-sandbox；翻新/拆件 IP 限制评估接 reverse-logistics；风险敞口供 risk-radar。

## 六、验收用例
- 正常：在德国销售但德国商标未注册的品牌，扫描输出裸奔市场卡与注册优先级。
- 战备：模拟美国律所 TRO 风险函件，P0 升级并联动资金冻结预案，24h 人工接管计时启动。

## 七、门道出处
- ★门道⑩固化技能：德国站专利投诉高发；IP 从"出事了找律师"变成"平时就有的免疫系统"。
