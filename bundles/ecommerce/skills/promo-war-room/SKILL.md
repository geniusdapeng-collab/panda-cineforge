# 大促战备模式

## 一、何时调用
- 大促日历 T-14 天自动进入备战、T-1 进入战时、大促结束 T+1 复员；老板手动启停。
- 战时 P0 连发（≥3 起/小时）自动提升战备等级。

## 二、输入契约
- 大促日历与场次排期；战备检查清单（库存深度/广告预算池/客服话术/凭据有效性/巡检频次配置）。
- 预审批池额度参数（大促价/广告档位/补货预案）；四路熔断阈值（预算池耗尽率/亏损速率/库存水位/绩效指标）。
- 值班排班资源池；巡检/夜班系统状态切换接口。

## 三、执行步骤（系统级状态切换）
1. **T-14 备战核验**：动作=战备检查清单逐项核验，缺口派单挂倒计时；产出物=备战核验表+缺口工单；回执=逐项回执。
2. **审批提速白名单**：动作=建立预审批池——大促价/大促广告档位/补货预案提前进 review-console 预审拍板；战时命中预审批池且额度内的动作 auto 放行，额度耗尽即恢复常规审批链；产出物=预审批池台账；回执=人工签署记录（T-14 前必签署）。
3. **熔断清单定义**：动作=设定四路熔断器阈值——预算池耗尽率/亏损速率/库存水位/绩效指标，触发即自动降档或暂停并即时告警；产出物=熔断配置单；回执=签署记录。
4. **T-1 战时切换**：动作=系统级状态变更——inspection-suite 切战备档（频次加密）、R16 夜班白名单战时临时扩展、全员战备排班表生成（班次/责任域/升级链）；产出物=状态切换记录+排班表；回执=各子系统确认回执（R27 模式切换 review 留痕）。
5. **战时指挥**：动作=每小时战报（GMV 进度/预算消耗/熔断触发/异常事件，聚合防风暴），P0 即时电话级触达；产出物=小时战报；回执=推送回执。
6. **T+1 复员**：动作=白名单与熔断阈值强制回收（防战时权限遗留），回收清单留痕审计，未回收项标红；输出大促复盘包（备战遗漏/熔断有效性/审批提速命中率）；产出物=回收清单+复盘包；回执=审计事件 ID。

## 四、边界与围栏
- 绑定 R27（战备模式切换必 review 留痕，状态变更可审计）、R30（战时高危审批仍不过期自动放行——提速的是"预审批"不是"免审批"）。
- 熔断阈值与提速白名单 T-14 前必人工签署；战备权限 T+1 强制回收，回收清单留痕审计。
- 战报聚合防风暴，但 P0 不得折叠。

## 五、与其他技能的协作
- 状态切换对象：inspection-suite（战备档）、night-ops-suite（白名单临时扩展）、handover-manager（战备班交接）。
- 数据：activity-enroll（大促报名方案）、promo-stockup（库存深度）；复盘回接 incident-postmortem。

## 六、验收用例
- 正常路径：战时广告预算池 2 小时耗尽 80% → 熔断器自动降档并即时告警。
- 异常路径：T+1 复员 → 输出权限回收清单，任何未回收战时白名单标红审计。
- 围栏触发：预审批池额度耗尽 → 恢复常规审批链；模式切换 → R27 review 留痕。

## 七、设计出处
- 来源：场景·系统级战备状态——大促是"平日全部风险×10 倍压缩到 72 小时"：全提速则失控、全卡审则失速；"预审批池+熔断清单"把提速建立在事先拍板之上、把失控锁死在物理熔断之内，这是大促从全员救火变体系作战的关键一跃。
