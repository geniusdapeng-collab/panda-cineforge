# 补货模型

## ① 何时调用
- 库存达再订货点事件即时触发；cron 每日 06:00 全量 SKU 补货体检；demand-forecast 预测更新广播联动重算。

## ② 输入契约
- demand-forecast 的 P50/P90 日均销量预测；SKU 供应链参数（采购周期/头程时效/MOQ/箱规）；库存数据（在库/在途）；safety-stock-calc 波动系数档位；现金池水位（采购优先级）。

## ③ 执行步骤
1. **参数装配**：读取预测日均销量与供应链参数。产出物：参数卡。回执：库存数据不全的 SKU 禁止自动补货。
2. **核心计算**：
   - **安全库存 = 日均销量 ×（采购周期 + 头程时效）× 波动系数**（波动系数=销量标准差/均值归一化：稳定款 1.2–1.5、波动款 1.5–2.5、大促期再×大促系数）。
   - **再订货点 = 安全库存 + 在途消耗 = 安全库存 + 日均销量 ×（采购周期 + 头程时效 ×1.5）**（1.5 为时效缓冲）。
   - **国内/跨境参数差异**：国内头程 2–5 天、缓冲取 1.2–1.5；跨境头程海运 25–40 天且另 +15 天清关容错、缓冲取 1.5–2.0，空运 5–10 天按国内口径。
   产出物：计算底稿（公式参数全列）。回执：底稿随单留痕可复算。
3. **补货量测算**：补货量 = 目标库存水位（再订货点+一个采购周期销量）− 在库 − 在途，按 MOQ/箱规取整。产出物：补货量建议。
4. **分级校验**：补货量超模型 ±20% 触发 review；SKU 损益未核算 block；现金池缺口时按利润款优先排序。产出物：校验记录。回执：超阈单挂审批卡片。
5. **采购建议单**：供应商/数量/到仓日期/资金占用测算，推送 purchase-order-auto。产出物：建议单。
6. **在途动态重算**：物流延误自动重算断货日期并升级告警。产出物：重算记录+告警。

## ④ 边界与围栏
- R7（review）：断货风险 <7 天且补货在途为 0，自动下紧急采购单请示。
- R20（review）：单笔采购 ≥¥5万 人审，≥¥50万 升 L4 人批。
- R23（block）：采购单生成≠付款，资金动作物理熔断，付款必人工。
- 模型参数由行业 Bundle 定默认，客户 Patch 只可收紧。

## ⑤ 与其他技能的协作
- 上游：demand-forecast/safety-stock-calc；下游：purchase-order-auto；联动：stockout-guard（断货日重算）、inventory-cashline（现金占用）、quick-return-supply（返单走本通道）。

## ⑥ 验收用例
- 输入 SKU（日均销 50、采购周期 7 天、头程 12 天、波动系数 1.5、在库 800、在途 300）→ 安全库存=50×19×1.5=1,425 件，再订货点=1,425+50×(7+18)=2,675 件，补货量按 MOQ 取整输出，底稿可复算。
- 补货量超模型 25% → review 挂起；损益未核算 SKU → block。
- 跨境海运 SKU → 计算底稿含 +15 天清关容错与 1.5–2.0 缓冲档。

## ⑦ 门道出处
- ★门道⑥：补货是「断货损失 vs 积压成本」的每日天平——公式化模型把这道算术题从采购员经验里拿出来，±20% 闸门保证系统误差不会直接变成现金损失。
