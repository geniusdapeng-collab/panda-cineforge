# 主播话术优化

## 一、何时调用
- live-review 话术关联分析任务卡驱动；cron 每周话术库健康度巡检。
- 新主播上岗生成定制话术包。

## 二、输入契约
- 直播录音转写语料、话术卡使用记录、对应时段转化数据切片（live-review）。
- 现行话术库版本、合规词库（live-compliance）、主播风格画像。

## 三、执行步骤
1. **语料采集**：动作=归集转写语料+话术卡使用记录+转化切片三对齐；产出物=对齐语料集；回执=语料覆盖场次清单。
2. **效果归因**：动作=对比"同一款商品用不同话术"的转化差异，识别高转化话术元素（痛点钩子类型/举证方式/逼单指令/比价锚点表达）；产出物=高转化元素清单；回执=对比样本量与显著性说明。
3. **话术库迭代**：动作=高转化话术升级主推模板、低效话术降级淘汰、违规擦边话术永久禁用（写入 forbidden）；产出物=库变更单；回执=版本号+变更依据。
4. **生成话术包**：动作=按主播风格（激情型/专业型/亲和型）匹配模板+每款商品话术卡（开场钩子/卖点举证/放价逼单/售后承诺标准表述）；产出物=个性化话术包；回执=话术卡过合规预检回执。
5. **灰度验证**：动作=新话术先在小场次试用，数据达标才进主库；产出物=灰度报告；回执=对照数据切片。
6. **版本管理**：动作=话术库每版留痕，效果数据随版本追踪；产出物=版本台账；回执=归档事件 ID。

## 四、边界与围栏
- 绑定 R21（涉费承诺类话术 review，"全网最低价"等无凭证承诺拦截）、R11（极限词/虚假宣传 block）、R16（话术发布必审，夜班不豁免）。
- 绝不做什么：绝不允许主播自由发挥售后承诺（只从审核过的标准表述库取）；绝不让价格话术与后台设置不一致（防口播破价）；绝不让违规话术进入灰度。

## 五、与其他技能的协作
- 输入：live-review（归因任务卡）；合规：live-compliance（预检/复检）。
- 输出：live-script（话术库）、live-copilot（实时话术卡推送）、clip-distribute（金句素材）。

## 六、验收用例
- 正常路径：10 场语料+转化切片 → 输出高转化话术元素清单、库升降级建议与新人话术包。
- 围栏触发：含违规表述的候选话术 → 拦截并给合规替换版。
- 灰度路径：新话术小场次数据不达标 → 不进主库并记录原因。

## 七、门道出处
- 门道⑨"经验不随人走"：金牌主播话术靠天赋、新人开播转化腰斩；话术资产化让新人拿话术卡即达 80 分，团队不因一个主播离职而崩盘。
