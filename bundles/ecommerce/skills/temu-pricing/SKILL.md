# Temu核价应对

## 一、何时调用
- 新品申报核价时即时触发报价测算。
- 平台核价驳回/压价通知事件驱动应对流程。
- cron 每周复盘核价通过率与供货毛利趋势。

## 二、输入契约
- 平台同款/近似款售价带抓取数据；本品到岸成本与毛利红线参数。
- 历史核价博弈档案（报价-驳回-成交记录）；平台核价驳回通知原文。
- 可替代渠道价格带地图（cross-platform-arbitrage）。

## 三、执行步骤
1. **核价前置测算**：动作=抓取平台同款/近似款售价带 → 扣除平台侧费用与预估物流，倒推出可被接受的供货价区间 → 与本品到岸成本+毛利红线比对，判定"可报/不可报/需降本后再报"；产出物=可报区间卡；回执=测算明细事件 ID。
2. **报价策略生成**：动作=三策略组合——首发报价锚定（预留核价压价空间但守红线）、规格差异化报价（组合装/差异化规格跳出同款比价池）、多站点错峰报价；产出物=报价方案；回执=方案版本号。
3. **驳回应对**：动作=分析驳回原因（价格高于预期/同款比价劣势），输出三案——降价重报（附毛利重算）/改规格重报/放弃该品转其他渠道（联动价格带地图）；产出物=应对方案卡；回执=review 单据号。
4. **博弈档案建档**：动作=每品报价-驳回-成交历史建档，提炼该类目平台压价幅度规律；产出物=类目压价规律卡；回执=档案事件 ID。
5. **周报复盘**：动作=核价通过率/供货毛利/驳回主因分布周报；产出物=周报；回执=推送回执。

## 四、边界与围栏
- 绑定 R2（供货价低于到岸成本×1.15 物理 block——核价博弈再凶也不做亏本供货）。
- 绑定 R11（以虚报规格/材质方式通过核价属虚假申报，block+forbidden）。
- Temu 线试验期预算封顶（R25 测款上限思路），追加必人工。
- 压价幅度超预期的类目输出"退出 Temu 该品类"的 honest 建议而非硬扛。

## 五、与其他技能的协作
- 成本：sku-profit-ledger（到岸成本与毛利红线）；渠道：cross-platform-arbitrage（转渠道三案）。
- 备货：promo-stockup（核价通过后备货联动）；周报送 multi-shop-matrix Temu 行。

## 六、验收用例
- 正常路径：平台同款售价带 $9.9–$12.9、本品到岸成本 $6 → 输出可报区间与首发锚定价。
- 异常路径：售价带抓取失败 → 标「未核实」不报价，写异常事件。
- 围栏触发：核价压至 $5.5（击穿红线）→ R2 block 并输出改规格/转渠道两案；虚报规格建议 → R11 block。

## 七、设计出处
- 来源：场景·Temu 半托管核价博弈——核价机制本质是"平台拿全网最低价反向压供货价"，多数卖家输在"为了过核价一路降到底"；倒推模型+红线闸门+规格差异化让核价从被动挨打变成有底线的谈判。
