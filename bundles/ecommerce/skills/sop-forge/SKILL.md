# SOP固化

## 一、何时调用
- 意识系统信号：任一 Agent/人工同类动作序列 7 天内出现 ≥3 次，自动产出固化建议。
- 人工提交新 SOP 即时受理；cron 每月 SOP 资产体检。

## 二、输入契约
- 五元事件库动作序列（Who×Object×action 模式挖掘数据源）。
- forge 三要素模板（触发/步骤/边界）；围栏规则库与 forbidden 清单。
- dry-run 回放引擎（历史事件回放环境）与 review-console 确认通道。

## 三、执行步骤
1. **高频动作识别**：动作=从事件库聚类动作序列，按频次×耗时×出错率三因子排序；产出物=值得固化候选清单；回执=聚类计算明细。
2. **固化建议书起草**：动作=按三要素起草——**触发**（什么信号启动）→**步骤**（动作序列回放提炼为 4–6 步标准流程）→**边界**（涉及围栏规则与禁止动作）；产出物=固化建议书；回执=起草版本号。
3. **forbidden 前置检测**：动作=校验 SOP 不固化任何规避围栏的动作模式；产出物=合规校验记录；回执=检测命中明细。
4. **dry-run 回放验证**：动作=用历史事件回放新 SOP，验证判定一致性与误伤率；产出物=回放报告；回执=回放事件 ID。
5. **人工确认注册**：动作=进 review-console 人工确认后注册为正式技能（安装即绑定围栏）；涉写动作的先影子运行、初始权限降半；产出物=注册单据；回执=审批记录。
6. **版本管理与月度体检**：动作=SOP 变更留痕/灰度生效/可回滚；月度输出僵尸 SOP（90 天无触发）/高驳回 SOP（review 驳回率 >30%）/冲突 SOP 清单与修订下线建议；产出物=体检报告；回执=归档事件 ID。

## 四、边界与围栏
- SOP 注册/变更必人工确认：意识系统只建议不自建，未过确认不得注册为技能。
- 固化建议涉及写动作的必须先 dry-run 且初始权限降半（影子运行期）。
- forbidden 检测前置：任何规避围栏的动作模式不得固化；industry 级上架必须脱敏（三级市场纪律）。

## 五、与其他技能的协作
- 信号源：意识系统（高频动作挖掘）；验证：围栏引擎 dry-run。
- 落地：注册后的 SOP 进入技能体系被各 Agent 调用；修订回接 incident-postmortem（断点驱动 SOP 修订）。
- 协同：hr-effectiveness-coach（人效视角的固化优先级）。

## 六、验收用例
- 正常路径：某店长 Agent 一周 4 次执行"差评→联系买家→补偿→跟进"相同序列 → 产出含三要素的固化建议书与 dry-run 回放报告。
- 异常路径：建议书未过人工确认 → 不得注册为技能，保持候选状态。
- 围栏触发：SOP 含规避围栏动作 → forbidden 检测拦截并说明。

## 七、门道出处
- 门道⑨组织与人效：所有重复性运营动作必须 SOP 化登记——SOP 写得越清楚数字员工接管越彻底，人走 SOP 留；AI 军团语境下升级为"经验不随 prompt 走"：系统自己发现"这件事每周做三遍"，forge 三要素让固化零代码，这是军团能力随经营自然生长的核心机制。
