# 逆向物流与换标重售

## 一、何时调用
- 跨境退货入海外仓质检通过事件触发分级流程。
- FBA 移除订单/不可售库存月度盘点触发处置评估。
- 国内退货签收质检完成触发回流分级。

## 二、输入契约
- 退货明细：SKU、退货原因、质检结果、残值评估。
- 换标/换包/翻新成本卡；重售渠道（原链接/二手渠道/批发清货）价格带。
- 品牌授权与知识产权限制清单。

## 三、执行步骤（操作手册）
1. 质检分级：A 级（未拆封可直接重售）/ B 级（包装破损需换标换包）/ C 级（功能完好需检测翻新）/ D 级（残次只能拆件或清仓）。
2. A/B 级进换标重售流水线：换标成本（人工+物料+仓储）vs 重售预期毛利，正收益才执行。
3. 重售渠道匹配：原链接重新上架 / 亚马逊 Warehouse 等二手渠道 / 批发清货渠道。
4. C 级翻新评估：翻新成本+保修风险定价，过审进官翻渠道，且必须如实标注"翻新"。
5. D 级残值回收：拆件可用性评估或批量折价处置，残值回收率记账。
6. 全链路 ROI 看板：退货回收金额、逆向物流成本、重售毛利率，按品类输出"退货变现率"排名反哺选品。

## 四、边界与围栏
- R11 直接 block：翻新机充当新品销售=虚假宣传；换标重售必须如实标注商品状态分级。
- 重售定价计入 SKU 损益账本且不得击穿 R2 毛利红线（清仓特例 review）。
- 涉品牌方知识产权限制的翻新/拆件销售，转 ip-shield 评估（对齐 R24 侵权闸门）。
- 批量处置回款核销必人工（R5/R23 资金纪律）。

## 五、与其他技能的协作
- 残值与损失落账 sku-profit-ledger；清仓分发联动 clearance-pricing；IP 限制评估转 ip-shield；变现率反哺选品域。

## 六、验收用例
- 正常：一批 B 级退货输出换标成本 ¥8/件 vs 重售毛利 ¥35/件的正收益执行单。
- 围栏：将翻新机按新品上架的请求被 R11 block。

## 七、门道出处
- 非★技能。来源：编制·reverse-logistics + 死因9·退货率失控（跨境退货直接销毁=100% 损失；3C/家居残值率可达 40%–70%）。
