# 优惠券满减设计 ★

## 一、何时调用
- 大促作战室联动生成促销方案；日常转化下滑 SKU 触发促销需求。
- cron 每周评估存量券 ROI，到期续设或停发。

## 二、输入契约
- 促销目标：拉新/提客单/清库存/防竞对（必选其一为主目标）。
- 店铺客单价分布、SKU 损益瀑布、人群包（audience-persona）、价格矩阵锚点。

## 三、执行步骤
1. **定目标**：动作=明确促销主目标与目标 SKU/人群范围；产出物=目标定义卡；回执=目标与货盘匹配校验记录。
2. **设计券结构**：动作=门槛（满减档=客单价×1.2 起跳，引导凑单）、面额（让利深度 vs 毛利影响逐档测算）、发放范围（全店/品类/单品/人群包定向）、时效；产出物=券结构方案（≥3 档候选）；回执=方案参数清单。
3. **过毛利闸门**：动作=按"券后成交价"测算预测净利率，提交 margin-guard；产出物=过闸结果；回执=RuleImpact 记录，触 R2 即打回并附反解。
4. **三方案对比**：动作=测算"券成本 vs 直降成本 vs 赠品成本"对比表（门道③ Checklist 必填项）；产出物=对比表；回执=测算口径说明。
5. **分流发放**：动作=常规券 auto 发放；单张让利 >客单价 15% 的大额定向券必 review；产出物=发券指令/审批卡片；回执=平台发券 API 回执。
6. **运行监控**：动作=监控核销率/凑单率/毛利侵蚀度，ROI 不达标自动停发；产出物=券效周报；回执=停发动作留痕。

## 四、边界与围栏
- 绑定 R2（券后价破红线 block）、R1（叠券后等效单日降幅>10% 挂起待审）、R11（"先涨后降"式虚假促销物理阻断，写入 forbidden）。
- 绝不做什么：绝不过闸前发券；绝不设计击穿红线的面额；绝不对价保期 SKU 发变相降价券（R13 联动）。

## 五、与其他技能的协作
- 闸门：margin-guard 前置；预算：券费用计入促销费用池受 budget-watch 监控。
- 协同：gift-strategy（赠品替代方案）、promo-planner（大促券包）、audience-persona（定向人群）。

## 六、验收用例
- 正常路径：客单价 120 元店铺 → 输出 149/199/299 三档门槛方案及各自净利测算与三方案对比表。
- 围栏触发："满100减50"类击穿红线方案 → block 并给出达标替代面额。
- 运行路径：某券核销率<基线 50% → 自动停发并留痕。

## 七、门道出处 ★
- 门道③"用满减、赠品替代直接降价"：满减的本质是"用门槛换让利"——好券提客单又保毛利，烂券白送利润；门槛-面额-人群三要素绑定毛利闸门，让每张券先有账再有券。
