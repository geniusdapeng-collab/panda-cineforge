# ACoS利润保险丝 ★

## 一、何时调用
- 管线内嵌闸门：每日两次巡检（10:00/22:00）+ 广告扣费/订单数据事件实时增量核算。
- 任何广告组创建/改价/加预算动作的前置校验。

## 二、输入契约
- sku-pl 每 SKU 最新损益瀑布（货品成本率/平台佣金率/物流费率/退货损耗率/仓储分摊率/税费率）。
- 广告组粒度花费与销售额数据（平台 API 回传，带时间戳）；测款白名单登记。

## 三、执行步骤
1. **算红线**：动作=从 sku-pl 读取每 SKU 参数，计算盈亏平衡 ACoS = 1 − 货品成本率 − 平台佣金率 − 物流费率 − 退货损耗率 − 仓储分摊率 − 税费率（即扣除全部非广告科目后的贡献利润率，如 25%）；产出物=SKU 红线表；回执=参数快照哈希，缺科目按最保守值计。
2. **核实绩**：动作=逐广告组核算实际 ACoS 与 TACoS（广告费/总销售额，防"广告漂亮总盘亏"）；产出物=实绩对照表；回执=数据源回执。
3. **一级熔断（降预算30%）**：动作=ACoS 连续 3 天 > 红线×1.2 → 自动降预算 30%，动作 auto、结果 review 备查（R3）；产出物=降预算指令；回执=平台 API 回执+RuleImpact（rule_id=R3，before/after/basis 齐全）。
4. **二级熔断（暂停单元）**：动作=ACoS > 红线×1.5 → 暂停广告组/单元，生成 review 请示卡；产出物=暂停指令+请示卡；回执=暂停回执+审批回执。
5. **三级熔断（计划冻结请示）**：动作=TACoS > 红线×1.3 或单计划连续熔断 2 次 → 冻结该计划全部调整权限，生成全店投放结构整改建议请示人工；产出物=冻结令+整改建议书；回执=冻结回执+升级通知（R30 超时升级不放行）。
6. **复评恢复**：动作=熔断后 T+7 复评，达标才允许按 ≤30% 梯度恢复预算；产出物=复评结论；回执=恢复动作留痕，恢复走 ads-budget-pacing 通道。

## 四、边界与围栏
- 绑定 R3（ACoS 连续3天>盈亏平衡点：自动降预算30%并请示，不可豁免）、R4（恢复/上调单次>30% 必审）、R30（高危审批超时升级而非放行）。
- 绝不做什么：绝不加预算（保险丝只降不升，加预算必走 ads-budget-pacing）；绝不豁免任何广告组（测款期 SKU 挂"战略亏损白名单"但有预算硬上限，耗尽即停）；绝不在缺损益科目时按乐观估值放行。

## 五、与其他技能的协作
- 数据：sku-pl（损益瀑布）；恢复通道：ads-budget-pacing；浪费排查：ads-audit。
- 被前置调用：ztc-campaign、qianchuan-campaign、amz-sp 等全平台投放技能的创建/改价/加预算动作。

## 六、验收用例
- 一级熔断：贡献利润率 25%、ACoS 连续 3 天 31%（>25%×1.2）→ 自动降预算 30% 并留痕。
- 二级熔断：同组 ACoS 达 38% → 触发暂停 review。
- 三级熔断：TACoS 超红线×1.3 → 计划冻结请示+结构整改建议。

## 七、门道出处 ★
- 门道⑤"贡献利润率决定盈亏平衡 ACoS"：死因3"广告烧钱无 ROI"的总开关（傲基半年销售费用 10.7 亿的教训）；自动熔断让"每一单广告都在亏钱"的状态物理上不可能持续超过 3 天。
