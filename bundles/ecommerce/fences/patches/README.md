# 客户级 Patch 模板（电商行业版 v1）

客户级 Patch 叠加在行业 Bundle 基线之上，**只可收紧不可放宽**（PRD 原话；单调守卫 F2.3 由底座强制执行）。
本目录三份模板对应三类客群（三客群装配：单平台多店腰部卖家 / 国内多平台大卖 / 跨境多平台超级大卖集团），seed/装载器只读取 `fences/ecom-baseline.yml`，
本目录文件为**客户接入时按客群类型选用的叠加模板**，不参与行业基线装载。

| 模板 | 客群 | 围栏松紧 | 夜班权重 | 典型场景 |
|---|---|---|---|---|
| waist-seller-patch.yml | 单平台多店腰部卖家 | 中（有人兜底） | 辅助 | 3-8 家店扎堆 1-2 个平台，运营+客服约 5 人 |
| cn-multi-patch.yml | 国内多平台大卖 | 中（运营总监兜底） | 辅助偏核心 | 天猫/京东/拼多多/抖快全线作战，大促战备权重高 |
| global-group-patch.yml | 跨境多平台超级大卖集团 | 紧（跨时区无人值守需严控） | 核心（王牌场景） | 国内+跨境两军，夜班班组承接欧美日间高峰 |

Patch 表达方式：对基线规则的 `when` 阈值做收紧覆盖（如 R1 单品单日降价 10%→5%），或把基线 review 升级为 block。
放宽（如 10%→15%、block 降级 review）会被单调守卫拒绝并留痕。
