# 客户级 Patch 模板（酒店行业版 v2）

客户级 Patch 叠加在行业 Bundle 基线之上，**只可收紧不可放宽**（PRD 原话；单调守卫 F2.3 由底座强制执行）。
本目录三份模板对应三类客群（任务三 §2.10 差异化矩阵），seed/装载器只读取 `fences/ecom-baseline.yml`，
本目录文件为**客户接入时按客群类型选用的叠加模板**，不参与行业基线装载。

| 模板 | 客群 | 围栏松紧 | 夜班权重 | 典型场景 |
|---|---|---|---|---|
| low-star-single-patch.yml | 低星单体酒店 | 中（有人兜底） | 辅助 | 20-50 间房，店长+前台+客房约 5 人 |
| homestay-patch.yml | 民宿 | 中（业主兜底） | 辅助 | 5-20 间房，业主/管家兼任，内容营销权重高 |
| unmanned-patch.yml | 无人酒店 | 紧（无人需严控） | 核心（王牌场景） | 全自助，1 远程店长按 3-5 家店 |

Patch 表达方式：对基线规则的 `when` 阈值做收紧覆盖（如 R1 涨幅 8%→5%），或把基线 review 升级为 block。
放宽（如 8%→10%、block 降级 review）会被单调守卫拒绝并留痕。
