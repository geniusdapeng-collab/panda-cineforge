## 二、AI 军团如何做到这一切（30% · 写给关心机制的人）

### 2.1 一支编队，而不是一个聊天框

WorkLoom 的 AI 不是「一个助手」，是**一支 82 人的数字军团，1+2+N 编制（81 业务编制 + 1 只读巡检员）**：

- **1 个集团指挥层（4 人）**：集团数字CEO、经营分析参谋、预算管控官、数字HR。
- **2 大作战军**：**国内作战军（26 人）**——天猫/京东/拼多多/抖音/快手/小红书/视频号/天猫国际 8 个平台战队；**跨境作战军（24 人）**——亚马逊/Temu/TikTok Shop/Shopee/速卖通&SHEIN/独立站 6 个战队 + 多语言客服中心。分军不是拍脑袋：平台规则、流量逻辑、履约链路、财税合规、语言时区全不同——**这与安克「事业部制 + 中台」的真实组织同构**。
- **5 个共享中台（27 人）**：数据/商品/供应链/财务/合规风控与内容客服——选品方法论、一盘货、财务口径、素材产能两军共享，不重复建设。
- **夜班班组**：每晚 22:00 自动出征——恰为欧美日间高峰：竞对采集 → 多平台对账 → 价格微调 → 清晨 08:30 交付三段式决策包（✓已完成/◆待审批/▲需介入）。任意时刻一键暂停，60 秒内全端生效，恢复后断点续跑。

  > **夜班的定义（电商版）**：夜班锚的从来不是"AI 的工作时间"——AI 本来就 24 小时全勤——而是**"人的离线时间"**。它是**人类免打扰时段的系统运行模式**，有四层实质：① **触达上免打扰**——非 P0 不叫人，全部聚合到清晨决策包（什么事配得上叫醒您，由系统先把关）；② **权限上自降级**——夜间仅白名单动作 auto、调价 ≤3%、高危审批超时升级而非自动放行，人不在线时系统自己把权力收小；③ **战场上是主场**——北京时间 22:00–08:00 恰为欧美日间高峰，别人睡觉时您的店还在赚钱（跨时区作战窗口）；④ **成本上是洼地**——对账/报表/批量内容生产在谷时算力窗口执行（费率 ≤20%）。一句话：**夜班服务的不是"夜晚"，是"人的离线"。**
- **技能市场**：161 个官方技能（含 48 个 ★ 门道固化 + fast-scan 快照快扫）是**可见、可装、可迭代的资产**，每项技能都带验收用例；使用采纳率回流驱动迭代。
- **意识系统**：高频重复工作被自动检测，每周产出「固化建议」——您一键确认，系统就把这件事变成自动触发器。**系统每周都比上周更懂您的店。**

### 2.2 安全不是承诺，是物理约束

- **围栏引擎 R1–R30**：一切动作 100% 经过三级判定——`auto` 放行 / `review` 挂起等您 30 秒审批 / `block` 熔断告警。售价低于货品成本 ×1.15？**系统物理上无法执行**——这不是提醒，是拒绝。
- **违规动作物理阻断**：刷单、删差评、虚假宣传、侵权词上架（R11 `block`）——写死在围栏里，模型再聪明也越不过去。
- **拒绝默认**：数据缺失时系统熔断而非猜测；多条规则命中取最严（deny 优先）；基线**只可收紧不可放宽**——任何自定义都在让系统更安全。
- **三手势审批**：涉钱、涉客、涉对外的动作（退款 ≥¥1000、赔偿 ≥¥500、广告日预算上调 >30%），必须您看清快照、给一句话理由、做一个手势。机器做 99%，**人的权威保留在最关键的 1%**。
- **安全禁区**：账号封禁风险、工商投诉、律师函级事件，AI 只告警 + 升级人工，**绝不自行处置**——红线写死在系统里，不靠模型自觉。

### 2.3 每一条记录都可以被验证

全部经营动作以五元事件（谁/何时/对什么/做了什么/规则影响）写入**哈希链**——逐条 SHA 锁定，包括系统自己的操作也不可篡改。多租户行级隔离、凭据不落明文、敏感信息脱敏入档。信任不靠品牌背书，**您可以当着我们的面逐条重算**。

### 2.4 产品理念：四个「反直觉」的坚持

> **拒绝默认**——宁可错杀，不可错放。
> **只紧不松**——围栏只能变严，不能变松。
> **断点是资产**——每次做不到，都必须让系统下次做得更好。
> **把夜晚还给卖家**——技术的终极指标，是人能不能睡个整觉。

## 二·五、数字CEO：让您的集团有一位真正的总经理（NEW · v3.0）

### 为什么要在电商团队里放一个「数字CEO」

过去两年，我们给卖家配齐了数字员工：调价的、盯广告的、回客服的、守夜班的。但卖家们很快发现了一个新问题——**员工越强，老板越忙**：每条策略要自己串，每个异常要自己判，每个动作要自己批。数字员工解决的是「手」的问题，没解决「脑」的问题。

人类的总经理做什么？三件事：**做决策、带团队、向董事会汇报**。数字CEO 就是把这三件事机器化——它统领 82 人数字军团，对经营结果负责，您（董事长）只做三件事：**提目标、听汇报、批少数关键决策**。

### 它能为您的生意带来什么（电商场景的价值）

| 场景 | 有了数字CEO 之后 |
|---|---|
| 每天调价与广告 | 微调它秒级直批；大促价格矩阵、广告大盘调整走**六步深度分析**（情报→案例回忆→多方案→红队挑刺→影响预估→建议书），重大决策试用期一律请您拍板 |
| 差评与投诉 | 常规它自主闭环；涉赔偿/公开承诺，形成「情况-选项-建议-依据」请示单，您 30 秒批完 |
| 夜班 | 夜班战队照旧干活，但次日汇报从「罗列事项」升级为 CEO 晨报：**做了什么/结果如何/需要您决策 0-N 件** |
| 团队管理 | 数字HR 每周给每个数字员工打分（表扬/关注/辅导）；连续不达标的，出具**汰换诊断书 + 新员工设计方案**报您批准——**汰换不是删除，是基因重组** |
| 多店多平台经营 | 店铺CEO → 事业部CEO → 集团CEO 三级汇报线，与五级审批路由对齐——**一人管十几家店的管理半径**，靠的就是这个编制 |

### 运行机制（可信比聪明更重要）

- **默认关闭**：每套系统的数字CEO 出厂即关闭；启用须您亲手完成**六步深度授权**（风险揭示/逐条确认/边界三滑杆/试用计划/身份核验/签署留痕）；
- **先影子后试用**：先当 3 天「影子」只模拟不执行，再 7 天试用（权力自动减半），**到期不自动续期**，长期保留或按季续任由您定；
- **五级权限**：小事它定（L2 店铺CEO 裁决），跨店/大额归集团CEO（L3），涉大钱/人/品牌/围栏放宽必请您（L4），安全禁区物理熔断（L5）；
- **经营剧场**：打开系统首页就是「熊猫运营中心」——国内战区/跨境战区/中台楼层/客服中心四层职场，82 名员工工位各就各位，数字CEO 站在指挥台中央，晨报它主动讲，请示它举着等您批，您有空看一眼，没空它也把店看得好好的；
- **全链留痕**：它的每一个决策、您的每一次授权与批准，都写进不可篡改的事件账（哈希链可验）。
