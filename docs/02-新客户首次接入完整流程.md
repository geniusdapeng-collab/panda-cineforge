# 新客户首次接入完整流程（电商版）

> 适用于多平台多店铺电商卖家。从装机到数字员工军团正式上岗约 30 分钟，全程无需技术人员。
> 主路径五步：**平台店铺授权 → 一盘货导入 → 员工编制选择 → 围栏确认 → 开启运行**。

---

## 第一步：平台店铺授权（约 10 分钟）

把工作交给军团之前，先让它看得见你的店：

1. 进入「落地向导」，按平台逐个完成店铺授权（天猫/京东/拼多多/抖音/快手/小红书/视频号/亚马逊/Temu/TikTok Shop/Shopee/独立站等）。
2. 官方 API 优先（L1）；暂不支持的平台走适配器（L2）/AI 浏览器剧本（L3），实在不行人工接管（L5）兜底。
3. 授权完成后，系统自动识别每家店的画像：平台、类目、价格带、毛利红线、广告红线、客服 SLA、合规禁区。

**这一步让数字员工拿到「读数」资格——只读不写，动钱动价都要过围栏。**

## 第二步：一盘货导入（约 5 分钟）

1. 导入 SPU/SKU 主数据（可从聚水潭等 ERP 或 Excel 导入——系统是 ERP 之上的决策层，与 ERP 共生而非替代）。
2. 补全供应商、仓网（国内仓/海外仓/FBA）、物流商档案。
3. 全球商品库官自动生成**一盘货视图**：条码映射、类目映射、多仓库存归一、成本与毛利红线建档。

## 第三步：员工编制选择（约 5 分钟）

按三客群模板一键装配你的数字员工军团：

| 客群模板 | 装配内容 | 适合谁 |
|---|---|---|
| 腰部卖家 | 平台战队 + 客服/售后共享组 + 轻量中台 | 单平台多店，3-8 家店 |
| 国内大卖 | 国内作战军满编 + 数据/商品中台 | 多平台全线作战 |
| 跨境集团 | 82 人满编：两军 + 5 中台 + 多语言客服中心 + 只读巡检员 | 国内+跨境，多币种多仓 |

每个数字员工的围栏绑定、夜班属性、工具读写权限随编制即刻生效。
**建议：先上客服与对账两个刚需岗，跑顺一周再扩编。**

## 第四步：围栏确认（约 5 分钟）

电商基线围栏 R1–R30 逐条过堂，出厂默认已经偏保守（只紧不松）：

| 级别 | 含义 | 默认包含 |
|---|---|---|
| auto 自动执行 | 数字员工直接做 | 数据整理、巡检、对账、报告生成 |
| review 需要批准 | 发卡片给你拍板 | 降价超阈值、广告预算上调、大额退款、涉费承诺 |
| block 禁止 | 物理不可执行 | 破毛利红线、刷单/删差评/侵权词、价保期改价 |

按需微调后保存，新规上线前可用历史动作 dry-run 回放预演。**涉及钱和买家的动作，默认都要经过你。**

## 第五步：开启运行（即刻）

- 数字员工军团开始 7×24 工作；夜班班组 22:00 接棒（欧美日间高峰主场）。
- 次日 8:30 你会收到第一份集团经营决策包（战果 ✓ / 待决断 ◆ / 求援 ▲）。
- 第一周内，建议每天花 5 分钟看决策包、处理审批卡片；一周后进入「每天 5 分钟」的常态。

## 接入检查单

- [ ] 平台店铺授权完成（至少 1 家店）
- [ ] 一盘货导入并生成一盘货视图
- [ ] 员工编制按客群模板装配
- [ ] 围栏 R1–R30 确认保存
- [ ] 夜班班组 22:00 首次接棒
- [ ] 收到第一份 08:30 集团经营决策包

完成以上六项，即接入成功。
