# 熊猫优选集团经营体验与演示指南（售前数字孪生 · 30 天经营态）

> 用途：**让客户在签约前，就看到「他买了之后会获得怎样的体验和回报」**。
> 一个年营收 102 亿人民币 + 53 亿美金超级大卖家的全模拟运行态：14 店铺 × 13 平台 × 81 人数字军团，
> 30 天经营数据与真实使用毫无区别（确定性生成、哈希链可验、全业务域覆盖），30 秒恢复，开箱即演。

## 三条命令

```bash
pnpm db:seed && pnpm demo:twin   # 种子 + 30 天经营模拟（约 2200 条五元事件）
pnpm demo:twin:snapshot          # 导出快照 → demo/twin/panda-30d.sql.gz（随仓库分发）
pnpm demo:twin:restore           # 售前现场：免模拟一键恢复（30 秒进入经营态）
```

## 推荐体验路径（10 分钟剧本）

1. **首屏定场（1'）**：restore 后打开 P1——「这是熊猫优选集团昨天的样子：14 家店、9.6 万单日订单口径，昨夜班组干了 14 项活，只有 1 件需要您拍板」。
2. **经营剧场巡场（1.5'）**：切经营剧场——81 名数字员工在四层工位上各司其职，跨境客服中心灯亮着（此刻正是欧美白天）——「这不是组织架构图，是正在干活的人」。
3. **审批三手势（1.5'）**：P4 决断队列——现场批准一条「ACoS 保险丝降预算」，再看一条已驳回的「补偿超档案口径」——「每个高风险动作都过人手，但人只管该管的」。
4. **大促作战室（2'）**：时间轴拉到第 20–22 天——黑五跨时区作战：订单脉冲 ×4、夜班班组全员战备、作战室日报零熔断——「大促不用全员熬夜，系统进入战备模式」。
5. **五线巡检与围栏（1.5'）**：P5——跟卖突袭取证驱赶（剧情⑥）、拼多多倒挂 15.7% 检出→处置→结果三段留痕（剧情⑩）；顺手演示一次 dry-run——「规则只能越收越紧，单调守卫拒绝放宽」。
6. **多模态客服（1.5'）**：客服监控墙看截图识别批次缺陷剧情（剧情⑫：买家截图 → 批次码聚合 → 质检派单 → 召回评估请示）；C 端前台现场发一张图问「找同款」。
7. **信任收口（1'）**：现场跑 `pnpm db:verify-chain`——「30 天 2200 条记录每一条都不可篡改，包括我们自己」。

## 质量保障

- **附录 E 校验**：写入逐条过 `safeParseBusinessEvent`，验收回读完整率 100%（不达标即失败退出）；
- **哈希链**：与生产同口径（`eventHash`/canonicalJson），`pnpm db:verify-chain` 现场可验——这本身就是售前的「防篡改」演示；
- **幂等**：重复执行事件冲突丢弃、审批不重复插入，任意重跑数据集逐字节一致；
- **确定性**：固定随机种子 + 固定时间窗，两次生成的快照可二进制比对。

## 三客群切换

快照默认是跨境多平台超级大卖集团（熊猫优选集团 14 店）视角。单平台多店腰部卖家/国内多平台大卖叙事用 `bundles/ecommerce/segment-defaults.yml` 的默认安装清单讲解即可（技能市场按客群命中对应排序）；快照内含云鹿家居（国内 5 店）/ 鲸落户外（跨境 3 店）两个托管客户工作区，可直接演示多客户驾驶舱。

## 真实模型接入（B8，v2.5.2 起）

意图路由（派遣框「安排任务/提问」的第一跳）支持真实大模型：

```bash
# .env
LLM_PROVIDER=openai            # openai 兼容：deepseek/moonshot/zhipu/openai 均可
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_API_KEY=sk-xxx
LLM_MODEL=deepseek-chat
```

- 配置后：dispatch 意图分类走真实模型（含提示词注入防护 + 输出白名单 + 3s 超时熔断），路由来源 `via=llm` 在任务卡留痕；
- 未配置（默认 `mock`）：确定性规则路由兜底（`via=rule`），全流程可跑（D4）；
- 模型出站强制脱敏（L6.2，任何调用路径不可绕过）。

**三模式真实运行口径（v2.6.0 起）**：
- **ask 问询**：即时应答——事实块实时取数（事件库/档案/审批队列），真模型合成回答（via=llm）；mock 下模板合成但**数字全真**（via=rule）。
- **agent 逐步商量**：规划后每一步挂起等人类确认（approvals 三手势推进一步走一步），直至 completed。
- **quest 自主执行**：真模型规划（B9——工具白名单校验 + 数据水合防 E2.1 误熔断 + 围栏逐步把关），未配置模型时确定性模板兜底。
- 演练路径（调价/差评/对账/巡检/夜班/大促等）建议优先；开放聊天的知识面取决于所接模型能力。
